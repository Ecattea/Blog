This placeholder post lives in `src/data/blog/`, which is the recommended location for published articles in this site.

When you start writing real posts, place them here:

- `src/data/blog/<slug>.md`
- `src/data/blog/<group>/<slug>.md` if you want grouped URLs later

Files or folders that start with `_` are treated as non-published content and will not be included in the site build.
